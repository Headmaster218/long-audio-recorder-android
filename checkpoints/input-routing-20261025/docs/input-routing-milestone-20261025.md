## 本阶段能力

- 支持选择手机麦克风，以及 Android 枚举出的有线／USB 输入；不宣称支持所有耳机，蓝牙明确不在本阶段支持范围内。
- 默认仅使用所选输入；设备丢失或实际路由无法核实即停止，需要明确重新开始。只有本次开始前显式勾选，才允许回退手机麦克风。
- 分别记录请求输入与观测到的实际输入。路由变化后，缓冲音频的来源不确定性持续标记至该 AudioRecord 运行结束，不声称无缝或逐样本精确切换。
- 输入策略拒绝不会被自动恢复重试绕过。保留权限、前台可见性、释放与单录音器约束；不启动 SCO，不改变通话模式，不接管通话音频。
- 手机回退在单次 AudioRecord 运行内保持；实验性恢复创建新运行时重新检查原始选择，界面已说明。
